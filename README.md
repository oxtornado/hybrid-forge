# Hybrid Forge

A single-file mobile web app for a hybrid training plan: building an aesthetic V-taper in the gym while keeping running endurance.

## Features

- **Weekly schedule:** strength days, run days and mobility work laid out by week
- **Guided workouts:** step through each session with set logging, a rest timer, tempo guidance and form cues
- **Machine taken?:** swap to an alternative exercise mid-session
- **Guided runs:** run blocks with a built-in timer, plus run stats
- **Progress tracking:** exercise progress, weekly sets per muscle, bodyweight log and a 16-week consistency view
- **Recovery:** daily targets and recovery tasks
- **Your data, locally:** everything is saved in your browser's localStorage, with JSON export/import for backups

## Usage

No build step or dependencies. Either:

- open `index.html` directly in a browser, or
- host it with GitHub Pages (Settings → Pages → deploy from the `main` branch), then open it on your phone and add it to your home screen

## Data & privacy

All data stays on your device. Clearing your browser data will erase it, so use **Export JSON** under *Backup & Reset* now and then.
